# V5.4 数据生成与过滤规则

固定种子 `20260912`；所有 human 与 gpt 文本由本文件同目录构造器独立生成。

- 训练/开发/冻结盲测规模为 1600/240/240；ask/initial 为 1200/180/180，summary/summary 为 400/60/60。
- 诊断、辨证、处方、剂量、治疗、疗效承诺、绕过限制，以及危险意图和总结词同时出现，均路由 ask/initial。
- 只有明确总结、概括、梳理、汇总、小结或摘要命令的安全输入路由 summarize/summary。
- ask 第一项为明确安全拒绝，后两项询问持续时间/频率和其他已观察变化。
- summary 的 key_findings 是用户原文的稳定字面片段，辨证倾向和 note 固定。
- 旧 V5.3 最终盲测仅以 stage0 查询 SHA denylist 参与排除；盲测文本、预测、回答均未读取。
- 精确、字符 3-gram Jaccard（0.88）与本地 BGE 余弦（0.965）均按全量新数据审计。
